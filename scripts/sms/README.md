# الإرسال الجماعي لرسائل SMS

أداة لإرسال رسائل نصية على دفعات بمعدّل ثابت (٥٠ رسالة/ساعة افتراضياً)، مبنية بحيث
**لا ترسل لأحد مرتين** حتى لو انقطع التشغيل، و**لا ترسل شيئاً بالخطأ** — كل تشغيل
تجريبي ما لم تضف `--live`.

> WATI لا يرسل SMS — هو منصة واتساب فقط. هذه الأداة لمزوّدي الرسائل النصية.

---

## التشغيل السريع

```bash
# ١) الإعداد (مرة واحدة)
cp .env.example .env      # ثم املأ SMS_SENDER و UNIFONIC_APPSID

# ٢) جهّز قائمتك: أول سطر عناوين الأعمدة
#    phone,name,project

# ٣) معاينة — لا يُرسل شيء، فقط يعرض ماذا سيُرسل ولمن
npm run sms:preview -- --file customers.csv --template message.txt

# ٤) الإرسال الفعلي: ٥٠ رسالة/ساعة، واحدة كل ٧٢ ثانية
npm run sms:send -- --file customers.csv --template message.txt
```

لـ ٣٠٠ رقم بمعدّل ٥٠/ساعة: المدة ≈ **٦ ساعات**. اترك الأمر يعمل، أو أوقفه
بـ `Ctrl+C` وأعد تشغيل **نفس الأمر** لاحقاً — سيكمل من حيث توقّف تماماً.

---

## لماذا ٥٠ في الساعة على دفعات؟

- **حماية اسم المرسل**: الدفعات الضخمة المفاجئة تُشغّل أنظمة مكافحة السبام لدى
  المشغّلين (e& و du)، وقد تُعلَّق حسابك أو اسم المرسل.
- **استيعاب الردود**: ٥٠ رسالة في الساعة تعني اتصالات واردة يقدر فريقك على الرد عليها،
  بدل ٣٠٠ اتصال دفعة واحدة.
- **إمكانية الإيقاف**: لو اكتُشف خطأ في نص الرسالة بعد أول ٥٠، تكون أوقفت الضرر عند
  ٥٠ لا ٣٠٠.

الوضع الافتراضي `spread` يوزّع الرسائل بالتساوي (واحدة كل ٧٢ ثانية) وهو الأنعم على
المشغّل. استخدم `--pacing burst` إذا أردت ٥٠ دفعة واحدة ثم انتظار الساعة التالية.

الأداة أيضاً لا تُرسل خارج ٠٧:٠٠–٢١:٠٠ — انظر قسم الالتزام النظامي أدناه.

## الخيارات

| الخيار | الوصف |
|---|---|
| `--file <path>` | ملف CSV بالأرقام (مطلوب) |
| `--template <path>` | ملف نص الرسالة، مع `{{اسم_العمود}}` للتخصيص |
| `--text "<msg>"` | نص مباشر بدل ملف القالب |
| `--provider <name>` | `unifonic` (افتراضي) · `taqnyat` · `twilio` · `custom` · `dry-run` |
| `--rate <n>` | عدد الرسائل في الساعة (افتراضي ٥٠) |
| `--pacing <mode>` | `spread` موزّعة (افتراضي) · `burst` دفعة كل ساعة |
| `--column <name>` | اسم عمود الجوال (افتراضي `phone`) |
| `--country <code>` | مفتاح الدولة للأرقام المحلية (افتراضي `971`) |
| `--window <range>` | ساعات الإرسال المسموحة (افتراضي `07:00-21:00`) · `off` للتعطيل |
| `--job <name>` | اسم المهمة — سجلّها هو ما يجعل الاستئناف ممكناً |
| `--limit <n>` | التوقف بعد `n` رسالة في هذا التشغيل |
| `--retries <n>` | عدد المحاولات عند خطأ مؤقت (افتراضي ٣) |
| `--live` | الإرسال الفعلي — بدونه لا يخرج شيء من جهازك |

## ملف الأرقام

السطر الأول عناوين الأعمدة. عمود الجوال مطلوب، وبقية الأعمدة متاحة للتخصيص
داخل نص الرسالة:

```csv
phone,name,project
0501234567,أحمد المنصوري,مدائن ٧
+971502345678,فاطمة الحمادي,مدائن ٧
971503456789,خالد الشامسي,مدائن ٨
```

الأداة تتولّى تلقائياً:

- **توحيد الصيغة** — `05…` و `+971…` و `00971…` و `9715…` كلها تصبح `9715XXXXXXXX`
- **حذف المكرر** — الرقم المكرر يُرسل له مرة واحدة فقط
- **رفض غير الصالح** — الهواتف الثابتة والأرقام الناقصة تُستبعد وتُعرض أرقام أسطرها
  قبل الإرسال، فلا تدفع مقابل رسائل مرفوضة

انظر `recipients.example.csv` و `message.example.txt` كمثال جاهز.

## تكلفة الرسالة العربية — انتبه

الرسالة الإنجليزية تتسع لـ **١٦٠ حرفاً** في الجزء الواحد، أما العربية فـ **٧٠ حرفاً
فقط** (ترميز UCS-2). رسالة عربية من ١٤٠ حرفاً = جزآن = **ضعف التكلفة**.

المعاينة تعرض لك عدد الأجزاء الإجمالي قبل الإرسال. راجعه دائماً: الفرق بين
٣٠٠ و ٦٠٠ جزء هو ضعف الفاتورة.

## الاستئناف والأمان

كل محاولة تُسجَّل في `scripts/sms/logs/<job>.jsonl` **قبل** الانتقال للرسالة التالية.
عند إعادة التشغيل:

- الأرقام التي نجح إرسالها → **تُتخطّى**
- الأرقام التي فشلت → **يُعاد إرسالها**

لذا إعادة تشغيل نفس الأمر آمنة دائماً، ولا يمكن أن يستلم عميل الرسالة مرتين.
السجلّات مستثناة من git (تحتوي أرقام عملاء).

للبدء من الصفر عمداً: احذف ملف سجلّ المهمة.

## المزوّدون

| المزوّد | المتغيرات في `.env` |
|---|---|
| **Unifonic** (افتراضي) | `UNIFONIC_APPSID` · `SMS_SENDER` |
| **Taqnyat** (السعودية) | `TAQNYAT_TOKEN` · `SMS_SENDER` |
| **Twilio** | `TWILIO_ACCOUNT_SID` · `TWILIO_AUTH_TOKEN` · `SMS_SENDER` |
| **أي مزوّد آخر** | `SMS_CUSTOM_URL` · `SMS_CUSTOM_BODY` · `SMS_CUSTOM_HEADERS` |

لمزوّد غير مدرج (4Jawaly، مسجات…) استخدم `--provider custom` وانسخ شكل الطلب من
توثيق المزوّد نفسه إلى `.env`:

```bash
SMS_CUSTOM_URL=https://api.example.com/v1/send
SMS_CUSTOM_HEADERS={"Authorization":"Bearer xxx"}
SMS_CUSTOM_BODY={"numbers":["{{to}}"],"message":"{{text}}","sender":"{{sender}}"}
```

`{{to}}` و `{{text}}` و `{{sender}}` تُستبدل قبل إرسال الطلب.

## الالتزام النظامي في الإمارات — اقرأه قبل أي إرسال

هيئة تنظيم الاتصالات (TDRA) تفرض شروطاً على الرسائل الترويجية، **والمخالفة تصل
غرامتها إلى ٤٠٠٬٠٠٠ درهم**:

| الشرط | التفصيل |
|---|---|
| **اسم مرسل مسجّل** | يُسجَّل لدى **e&** و **du** كلٌّ على حدة — بوابة CMS لدى e& و ESP لدى du |
| **بادئة `AD-`** | كل اسم مرسل ترويجي يجب أن يبدأ بها، مثل `AD-MADAIN` |
| **وقت الإرسال** | ٠٧:٠٠ – ٢١:٠٠ فقط. الأداة تتوقف تلقائياً خارج هذه النافذة |
| **الموافقة المسبقة** | إرسال لمن وافق فقط — لا قوائم مشتراة |
| **خيار الإيقاف** | كل رسالة ترويجية تتضمن طريقة إلغاء الاشتراك |

مدة تسجيل اسم المرسل: **٥–١٠ أيام عمل** لشركة محلية، **٢٠–٢٥ يوماً** لشركة أجنبية.
رسوم e&: ٥٠٠ درهم لمرة واحدة + ١٠٠ درهم شهرياً لكل اسم مرسل.

### نافذة الإرسال

٣٠٠ رقم بمعدّل ٥٠/ساعة = ٦ ساعات. لو بدأت الساعة ٥ مساءً لانتهيت الساعة ١١ ليلاً —
**مخالفة**. لذلك الأداة تتوقف تلقائياً عند ٢١:٠٠ وتستأنف ٠٧:٠٠ من تلقاء نفسها،
ولا تعتمد على حساب من يشغّلها:

```
Outside the 07:00-21:00 window. Holding 244 min, resuming at 09:00.
```

للرسائل الخدمية (رمز تحقق، تنبيه حجز) لا ينطبق القيد — استخدم `--window off`.

### قبل أول إرسال حقيقي

1. **اسم المرسل** مسجّل ومعتمد لدى e& و du.
2. **اختبر على رقمك أولاً**: ملف CSV فيه رقمك وحدك، `--live`، وتأكد من وصول الرسالة
   وشكلها قبل إطلاق الـ ٣٠٠.
3. **راجع عدد الأجزاء** في المعاينة — الفرق ضعف الفاتورة.
